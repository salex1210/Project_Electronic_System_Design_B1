# Project_Electronic_System_Design_B1

This study presents the design and implementation of an analog control voltage generation system aimed at voltammetric applications. The proposed system employs the LTC2644 digital-to-analog converter, a microcontroller, and operational amplifiers, organized within a three-stage architecture: (1) generation of a dual power supply from a single 5 V source using the ICL7660, (2) conversion of PWM signals into stable analog outputs via the LTC2644, and (3) signal conditioning to adjust the output range for electrochemical measurements. To preserve the integrity of the analog signals, galvanic isolation was implemented using optocouplers.  Simulations were conducted in Proteus to validate the theoretical behavior of the circuit, and a two-layer printed circuit board (PCB) was designed, optimizing the component layout and signal routing. Experimental tests confirmed the system's functionality, enabling the generation of stable and precise linear sweep and differential pulse voltammetry scans. The results demonstrate that the system offers a compact, cost-effective, and high-performance solution for the control of high-precision voltammetric experiments.
